# Skill de copywriting pra IA

Skill reutilizável para criar e revisar copy de landing pages de venda. O fluxo cobre briefing, confirmação, entrega estruturada em 15 blocos e avaliação opcional com rubrica.

## Conteúdo

- `SKILL.md`: instruções completas da skill `landing-page-copy`.

## Instalação manual

Copie `SKILL.md` para `.agents/skills/landing-page-copy/SKILL.md` em um projeto compatível com Agent Skills.

## Avaliação

A avaliação exige a rubrica `assets/rubrica.md`. Se ela não estiver disponível no projeto, a skill solicita o arquivo e não atribui notas sem consultá-lo.
